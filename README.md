# Shamin Vihanga — Black Portfolio

Static portfolio website prepared for GitHub Pages.

## Pages
- `index.html` — main black-theme portfolio
- `profile.html` — dashboard-style profile page

## Included
- CV details, experience, education, skills, languages and referees
- Cisco verified badge images
- LinkedIn, Facebook, Instagram, YouTube and TikTok links
- Downloadable CV
- GitHub Pages `CNAME` configured for `shamin.online`

## Publish/update on GitHub Pages
Upload all files and the `assets` folder to the root of the `shamin-portfolio` repository and commit. GitHub Pages will redeploy automatically.

## Profile photo
The current package uses `assets/profile.png`. Replace only that file (keep the same filename) to change the photo everywhere on the site.
